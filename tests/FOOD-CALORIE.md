# 음식 칼로리 계산기

`food-calorie.html`을 Live Server 또는 일반 정적 서버로 열면 됩니다. 프레임워크, 빌드, API 키가 필요하지 않습니다. 기존 HOME, Header, Footer에 있던 `food-calorie.html#home` 링크를 그대로 사용합니다.

## 파일 역할

- `assets/js/food-data.js`: 100g 기준 로컬 식품 자료 및 식품별 출처
- `assets/js/food-core.js`: 입력 검증, 검색, 비례 계산, 합계, 날짜, 영양소 비율
- `assets/js/food-storage.js`: 날짜별 localStorage 저장, 손상 자료 보호, 저장 실패 처리
- `assets/js/food-main.js`: jQuery 화면 이벤트와 결과 렌더링
- `assets/css/food-style.css`: 새 페이지에 한정된 스타일

## 저장과 예외

- 저장 키: `fitcalc-food-log-v1:YYYY-MM-DD`, 브라우저의 로컬 날짜 기준
- 새로고침 시 오늘 날짜를 표시하며 과거 기록은 날짜 선택으로 조회합니다.
- 0.1~5000g, 소수점 첫째 자리까지 허용합니다. 슬라이더만 1~1000g에 고정됩니다.
- 계산과 저장은 반올림 전 수치를 사용합니다. 화면 열량은 정수, 영양소는 소수점 첫째 자리입니다.
- 빈 영양소는 `null`로 저장합니다. 부분 합계와 알려진 영양소만의 비율임을 표시합니다.
- 잘못된 저장 자료는 자동 덮어쓰지 않습니다. 선택 날짜 전체 삭제로 해당 키를 초기화할 수 있습니다.
- 저장 거부/용량 초과 시 현재 탭에서만 임시 보관하며 경고합니다. 브라우저 데이터 삭제 및 동기화는 지원하지 않습니다.

## 검증

프로젝트 상위 폴더에서 `node FITCALC/tests/food-core.test.cjs`를 실행합니다.

브라우저 검증은 Playwright를 사용할 수 있는 환경에서 `node FITCALC/tests/food-browser.test.cjs`를 실행합니다. 필요하면 `NODE_PATH`로 패키지 경로, `BROWSER_PATH`로 Chromium 실행 파일을 지정합니다. 테스트 서버는 임의 로컬 포트를 사용하고 별도 임시 브라우저 프로필에서만 데이터를 만듭니다.
